I Recently bought the Starlite 5, a convertible Linux Tablet from Starlabs systems, a relativly small company from the UK focusing on desinging devices specifically for Linux.
In order to make a judgement if such a device fits your needs, i tried to clearly identify the usage scenarios the device would serve for me. Basically, it is supposed to serve 2 purposes for me:
1. function as a regular tablet: I previiouly owned an android tablet (lenovo tab 10) which was cheap at the time and has aged (not very well, I might add). I used it for watching videos, browsing, reading e-books, sometimes some games. A new hyrid device should be suitable for these purposes as well.
2. use as linux laptop for situations, where portablility is requred, e.g. when traveling or visiting relatives. It being linux, it is usable for much deeper tasks such as maintainance of servers via ssh, programming etc.


## The Hardware

Overall, I am very happy with the build quality. 
It is a bit on the heavy side (for comaprison, the pixel tablet only weights 500 grams (its only a 10 inch screen)).

### Display

The Display is very sharp and so far always bright enough for my usage. Only thing that would be nice to have is more than 60 herz refresh rate. I really appreciate the 90 hz my Pixel 7 phone, which makes everythink feel just that little bit smooter. One more thing worth noting is that the base resolution is so high 2160x1440px, that I use it at 150% scaling, as icons are otherwise a bit too small for my liking. I mention this, because scaling is, at least in case of the Gnome desktop leading to a slightly less sharp image. Other than that, I can't complain. 

### CPU/RAM
I got the nerwer revision of the Starlite 5 with the Intel N350 processor, 16 GB DDR5 RAM and 1TB of Storage. For eveyday usage like browsing, it feels very snappy (at least on chromium based browsers. I find firefox a bit slower) and watching videos and live-streams. It is even powerful enough to run some small games on Steam, like Brotato.
Overall, do not expect performance you would get on comparably priced windows devices, but it is powerfull enough for most tasks you would do on a regular mid-range laptop.

### Cameras
Both the front and backcameras can be adressed in the OS (which is not nessessarily obvious on linux). They are almost comically bad and I would never want to use them in a meeting let alone take a picture.

## Assessoirs

### Keyboard Case

The Keyboard is generally good to type on. As with similar keyboard cases, you basically require a flat surface to properly place the device on in order to have stability, which can be a bit annoying when e.g. using it in bed. 
I have the issue that sometimes the touchpad is not working, often requireing a reboot.

### Pen
I works well. I am not an artist, but it get's the job done for some scetches and handwriting.

### Others

The Micro HDMI and Charging Cables work as expected and are of good quality. 


## The Software
I got mine shipped with the Ubuntu 24.04 Gnome Version. I have not tried any other distros so I can speak only on it. It generally runs very smoothly, but it takes some getting used to, e.g. from other touchscreen devices, you are probably used to clicking into a text field, like your browsers adress bar und would exect an onscreen Keyboard to pop up. By default this is not the case on the StarLite. instead you need to open the onscreen keybord by swping up from the bottom of the screen. 
Speaking of the touchscreen, the compatibitly is sadly limited for some applications. E.g. I would be intuitive to be able to scroll in VS code by swiping the page up or down but it is not supported. (there are some hacks available but I have so far not been able to get it to work) -> update: this now works smoothly out of the box.

### Some Ideas/Tipps for FOSS to try on the Starlite
 - Waydroid: Android Emulation
 - Winboard: Windows emulation (can be used to start single apps)
 - Readly: free google books alternative
 - Clapper: Video Player with very good out-of-the-box touchscreen support (After trying quite a few options, like VLC, Celluloid, I settled on that one)


## Conclusion

If asked if I could recommend it, I would say yes, even tough the price tag is quite hefty for what you are getting. It really depends on what you are planning to use it for. If it is supposed to replace a regular Android or iOS tablet used for streaming videos, reading, browsing etc. I am pretty sure there are better/cheapter options out there.
If you are looking for what basically is an ultra portable Linux Laptop suitable for more advanced tasks such as programming, document writing or working on a proper command line interface with the option to be used without a keyboard, the Starlite 5 could be something for you :)  

Also, to make a more ideological argument, I like to idea to support hardware specifically made for linux and appreciate the contributions Star Labs is making to the open source community.
